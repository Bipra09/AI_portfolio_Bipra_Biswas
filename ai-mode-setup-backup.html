Complete Setup Instructions

📋 Prerequisites
  1. Node.js (version 16 or higher) - Download from https://nodejs.org/
  2. Hugging Face Account - Sign up at https://huggingface.co/
  3. Basic Terminal Knowledge - Ability to run commands
🔑 Step 1: Get Your Hugging Face Token
  1. Visit Hugging Face Settings
  2. Click "New token"
  3. Give it a name (e.g., "Friday AI Portfolio")
  4. Select "Read" permissions
  5. Copy the generated token (starts with hf_)
🚀 Step 2: Start the Backend Server
  1. Open Terminal/Command Prompt in your portfolio folder
  2. Install Dependencies: npm install
  3. Start Server: npm start
  4. Verify Server: Open http://localhost:3000/api/health
📁 Alternative: Use Startup Scripts

Windows: Double-click start-friday-ai.bat

PowerShell: Right-click start-friday-ai.ps1 → "Run with PowerShell"

⚙️ Step 3: Configure AI Mode Setup
  1. Enter Token: Paste your Hugging Face token in the field above
  2. Click "Validate Token" to verify access
  3. Click "Test Connection" to verify server
  4. Click "Activate Online Mode" when ready
🔄 Switching Between Modes
  1. To Online Mode: Complete setup above and click "Activate Online Mode"
  2. To Offline Mode: Go to setup page and click "Deactivate Online Mode"
  3. Automatic Fallback: If online fails, automatically switches to offline
