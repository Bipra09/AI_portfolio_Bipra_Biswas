Setup Instructions

  1. Get Hugging Face Token: Visit https://huggingface.co/settings/tokens and create a new access token with read permissions.
  2. Choose Model: Select your preferred AI model from the dropdown. Popular options include Google Gemma, Meta Llama, and Mistral AI models.
  3. Configure Server: Set your preferred port (default: 3000) and ensure it's not in use by other applications.
  4. Test Connection: Use the "Test Connection" button to verify your setup is working correctly.
  5. Save Configuration: Click "Save Configuration" to store your settings for future use.
  6. Start Backend: Run node ai-backend-server.js in your terminal to start the AI backend server.
