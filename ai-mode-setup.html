🤖 AI Setup Guide

Complete guide to connect your AI assistant with Hugging Face for online AI capabilities

Step 1: Hugging Face Token Setup

Get Your Hugging Face Access Token

  1. Visit Hugging Face: Go to https://huggingface.co/settings/tokens
  2. Sign In: Log in to your Hugging Face account (create one if you don't have it)
  3. Create Token: Click "New token" and give it a name (e.g., "AI Assistant")
  4. Set Permissions: Select "Read" permissions (this is sufficient for AI model access)
  5. Copy Token: Copy the generated token (starts with "hf_")

Step 3: Complete Setup Guide

📋 Step-by-Step Setup Process

1. Get Hugging Face Token

Visit https://huggingface.co/settings/tokens

  • Sign in to your Hugging Face account
  • Click "New token" and name it "AI Assistant"
  • Set permissions to "Read" only
  • Copy the generated token (starts with "hf_")

2. Configure Backend Server

  • Set server port (default: 3000)
  • Ensure the port is not used by other applications
  • Test the connection using the "Test Connection" button

3. Start the AI Backend Server

# Open terminal in your project folder
node ai-backend-server.js

Important: Keep this terminal running while using AI online mode.

4. Activate Online Mode

  • Once your token is validated and server is running
  • Click "Activate Online AI Mode" button
  • Your AI will now use Hugging Face models for responses

Complete Setup Instructions

📋 Prerequisites
  1. Node.js (version 16 or higher) - Download from https://nodejs.org/
  2. Hugging Face Account - Sign up at https://huggingface.co/
  3. Basic Terminal Knowledge - Ability to run commands
🔑 Step 1: Get Your Hugging Face Token
  1. Visit Hugging Face Settings
  2. Click "New token"
  3. Give it a name (e.g., "AI Portfolio")
  4. Select "Read" permissions
  5. Copy the generated token (starts with hf_)
🚀 Step 2: Start the Backend Server
  1. Open Terminal/Command Prompt in your portfolio folder
  2. Install Dependencies: npm install
  3. Start Server: npm start
  4. Verify Server: Open http://localhost:3000/api/health
📁 Alternative: Use Startup Scripts

Windows: Double-click start-ai.bat

PowerShell: Right-click start-ai.ps1 → "Run with PowerShell"

⚙️ Step 3: Configure AI Mode Setup
  1. Enter Token: Paste your Hugging Face token in the field above
  2. Click "Validate Token" to verify access
  3. Click "Test Connection" to verify server
  4. Click "Activate Online Mode" when ready
🔄 Switching Between Modes
  1. To Online Mode: Complete setup above and click "Activate Online Mode"
  2. To Offline Mode: Go to setup page and click "Deactivate Online Mode"
  3. Automatic Fallback: If online fails, automatically switches to offline
