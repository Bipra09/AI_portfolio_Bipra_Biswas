# 🚀 Quick Start - Friday AI Backend

## ⚡ Get Running in 3 Steps

### 1. Create Environment File
Create a file named `.env` in the `friday-ai-backend` folder:
```
HF_TOKEN=your_huggingface_token_here
PORT=5000
```

### 2. Start the Server
**Windows (PowerShell):**
```powershell
cd friday-ai-backend
npm start
```

**Or use the provided script:**
- Double-click `start.bat` (Windows)
- Or run `start.ps1` in PowerShell

### 3. Test It
Open `test-ai.html` in your browser and ask Friday AI anything!
